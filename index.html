myPulse pkg Repository

GitHub Pages package repository for os-mypulse — the OPNsense plugin for Olilo myPulse monitoring.

Quick Install

# Add repository configuration
echo 'myPulse: { url: "https://x13-me.github.io/myPulse-repo/pkg", enabled: yes }' > /usr/local/etc/pkg/repos/myPulse.conf

# Update and install
pkg update
pkg install os-mypulse

Repository Contents

  • os-mypulse-0.2.3.pkg — OPNsense plugin package
  • os-mypulse-0.2.3.pkg.sha256 — SHA256 checksum
  • packagesite.txz — Repository catalog
Note: This repository is automatically updated by GitHub Actions when new tags are pushed to the upstream pulse-agent-opnsense repository.

Manual Install

# Download and install directly
fetch https://github.com/x13-me/myPulse-repo/releases/latest/download/os-mypulse-0.2.3.pkg
pkg add os-mypulse-0.2.3.pkg
