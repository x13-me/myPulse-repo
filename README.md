# myPulse Build Repository

GitHub Actions infrastructure for building, packaging, and distributing `os-mypulse` — the OPNsense plugin for Olilo myPulse monitoring.

## Overview

This repository provides:

1. **Automated builds** — FreeBSD 15.1 builds via `vmactions/freebsd-vm`
2. **Package repository** — Hosted on GitHub Pages for `pkg add` installation
3. **Release artifacts** — GitHub Releases with .pkg files
4. **Upstream integration** — Triggered via `repository_dispatch` from GitLab

## Architecture

```
┌─────────────────┐     repository_dispatch      ┌──────────────────┐
│  GitLab (upstream)  ──────────────────────────▶ │  GitHub Actions  │
│  ryanstead/pulse-   {event_type: build_os_mypulse}│  vmactions/      │
│  agent-opnsense    {client_payload: {ref, version}}│  freebsd-vm     │
└─────────────────┘                               └────────┬─────────┘
                                                            │
                        ┌───────────────────────────────────┼───────────────┐
                        ▼                                   ▼               ▼
               ┌─────────────────┐               ┌─────────────────┐ ┌──────────────┐
               │  GitHub Pages   │               │ GitHub Releases │ │  GitLab      │
               │  pkg repo       │               │  .pkg artifact  │ │  (optional)  │
               │  https://...    │               │  os-mypulse-*.pkg│ │  releases    │
               └─────────────────┘               └─────────────────┘ └──────────────┘
```

## Quick Start (for users)

### Install from GitHub Pages pkg repo

```sh
# Add repo config
echo 'myPulse: { url: "https://github.x13.me/myPulse-repo/pkg", enabled: yes, priority: 20 }' > /usr/local/etc/pkg/repos/myPulse.conf

# Update and install
pkg update
pkg install os-mypulse
```

### Manual install from GitHub Releases

```sh
# Download latest
fetch https://github.com/x13-me/myPulse-repo/releases/latest/download/os-mypulse-0.2.3.pkg
pkg add os-mypulse-0.2.3.pkg
```

## Triggering a Build

### From GitLab (upstream)

Add a webhook in GitLab: `Settings → Webhooks`

- **URL**: `https://api.github.com/repos/x13-me/myPulse-repo/dispatches`
- **Secret**: (optional) HMAC secret
- **Trigger**: Push events, Tag push events
- **Headers**: `Content-Type: application/json`

GitLab webhook payload will be transformed by GitHub Actions.

### Manual trigger

```sh
# Via GitHub CLI
gh workflow run build.yml -f ref=v0.2.3 -f version=0.2.3

# Via API
curl -X POST https://api.github.com/repos/x13-me/myPulse-repo/dispatches \
  -H "Authorization: Bearer $GITHUB_TOKEN" \
  -H "Accept: application/vnd.github.v3+json" \
  -d '{"event_type": "build_os_mypulse", "client_payload": {"ref": "v0.2.3", "version": "0.2.3"}}'
```

## Required Secrets

Configure in GitHub: `Settings → Secrets and variables → Actions`

| Secret | Description | Required |
|--------|-------------|----------|
| `UPSTREAM_PAT` | GitLab Personal Access Token with `read_repository` scope | Yes |
| `GITLAB_TOKEN` | GitLab token with `write_package_registry` scope (optional) | No |

## pkg Repository Structure

```
https://github.x13.me/myPulse-repo/
├── os-mypulse-0.2.3.pkg
├── os-mypulse-0.2.3.pkg.sha256
├── packagesite.txz          # Generated by `pkg repo`
└── meta.txz                 # Repository metadata
```

Users configure in `/usr/local/etc/pkg/repos/myPulse.conf`:

```conf
myPulse: {
  url: "https://github.x13.me/myPulse-repo/pkg",
  enabled: yes,
  priority: 20,
  signature_type: "none",
  fingerprints: "/usr/local/etc/pkg/fingerprints/OPNsense"
}
```

## Upstream Integration (GitLab)

### 1. Add GitHub PAT to GitLab CI/CD variables

`Settings → CI/CD → Variables`
- `GITHUB_DISPATCH_TOKEN` = GitHub PAT with `repo` scope

### 2. Add webhook or CI job

**Option A: GitLab Webhook**
- URL: `https://api.github.com/repos/x13-me/myPulse-repo/dispatches`
- Secret: (matching GitHub secret if configured)
- Events: Push, Tag push

**Option B: GitLab CI/CD Job** (`.gitlab-ci.yml` in upstream)

```yaml
trigger_build:
  stage: deploy
  image: curlimages/curl:latest
  rules:
    - if: $CI_COMMIT_TAG
  script:
    - |
      curl -X POST https://api.github.com/repos/x13-me/myPulse-repo/dispatches \
        -H "Authorization: Bearer $GITHUB_DISPATCH_TOKEN" \
        -H "Accept: application/vnd.github.v3+json" \
        -d "{\"event_type\": \"build_os_mypulse\", \"client_payload\": {\"ref\": \"$CI_COMMIT_TAG\", \"version\": \"${CI_COMMIT_TAG#v}\"}}"
```
